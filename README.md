# Анализ текстов и классификация тональности

Тестовое задание по ML на русскоязычных текстах. В работе есть анализ данных, поиск тем и обучение классификатора тональности. Все эксперименты и выводы находятся в [ml_test.ipynb](ml_test.ipynb).

Основной notebook уже содержит результаты, таблицы и графики. Для их просмотра обучение запускать не нужно. Для проверки готовой модели на своём тексте есть отдельный скрипт и небольшой [demo.ipynb](demo.ipynb).

## Результаты

Качество на очищенной тестовой выборке из 20 074 текстов

| Модель | Accuracy | Macro-F1 |
|---|---:|---:|
| TF-IDF + LogisticRegression | 0,7687 | 0,7566 |
| RuBERT-tiny2 | **0,8080** | **0,7964** |

Нейросеть прибавила 3,98 процентного пункта Macro-F1. Лучшая эпоха выбрана по validation, после этого настройки по test не менялись. Для поиска тем использовалась отдельная связка TF-IDF + NMF с 15 компонентами.

На Apple M1 Pro с 16 ГиБ памяти модель на CPU и GPU дала одинаковые классы на всём test. При батче 32 получено 136,5 документов/с на CPU и 490,9 на GPU через MPS. При батче 1 CPU оказался быстрее — 96,8 против 61,7 документов/с. Измерения не включают токенизацию и загрузку модели. Подробная методика есть в notebook.

## Проверить готовую модель

Нужен Python 3.12. Следующие команды выполняются из корня проекта. Способ установки через `uv` показан для macOS/Linux, сам скрипт по умолчанию использует CPU.

```bash
uv venv --python 3.12
source .venv/bin/activate
uv pip install -r requirements-inference.txt
```

Скачайте `rubert_tiny2_best.zip` из раздела **Releases** этого репозитория и распакуйте в корень проекта. Архив уже содержит нужный путь `artifacts/rubert_tiny2_best/`.

```bash
unzip rubert_tiny2_best.zip -d .
python predict.py --text "Отличный отель, обязательно вернусь!"
```

Для нескольких текстов

```bash
python predict.py --text "Всё понравилось" "Обслуживание ужасное"
```

Для файла UTF-8, в котором каждый текст занимает одну строку

```bash
python predict.py --file reviews.txt --batch-size 32
```

Вывод содержит текст, выбранную тональность и оценки вероятностей трёх классов. Вероятности отдельно не калибровались. Тексты длиннее 256 токенов обрезаются, пустые строки в файле пропускаются. Модель может ошибаться, особенно на смешанных оценках.

Модель загружается только из локальных файлов, тексты не отправляются во внешний API. Для Apple GPU можно добавить `--device mps`, для поддерживаемого NVIDIA GPU — `--device cuda`. Основная проверенная конфигурация этого проекта — Apple M1 Pro; проверок CUDA не проводилось.

Для демонстрации через Jupyter установите полные зависимости и откройте `demo.ipynb`. В нём только загрузка готовых весов и предсказания.

## Полный эксперимент

```bash
uv pip install -r requirements.txt
jupyter lab
```

Откройте `ml_test.ipynb`. Полное выполнение ячеек сверху вниз повторяет загрузку данных, анализ и обучение, а затем перезаписывает результаты в `artifacts`. Три эпохи нейросети на M1 Pro заняли около 90 минут. Для повторной проверки готовой модели достаточно `predict.py` или `demo.ipynb`.

Некоторые ячейки полного notebook используют `uv`, `curl`, macOS `sysctl` и Apple MPS. Notebook ориентирован на окружение эксперимента; при переносе аппаратных измерений на другую ОС соответствующие ячейки потребуется адаптировать. Полный список версий — снимок использованного macOS-окружения, короткий `requirements-inference.txt` содержит прямые зависимости для демонстрации.

## Данные и подход

Использованы `train.csv` и `valid.csv` из [MonoHime/ru_sentiment_dataset](https://huggingface.co/datasets/MonoHime/ru_sentiment_dataset). Исходные CSV скачиваются кодом и в Git не включены.

До обучения исключены тексты с противоречивыми метками, точные повторы и пересечения. Очищенный исходный `valid.csv` отведён под test, оставшийся train разделён со стратификацией. Получилось 150 202 / 26 507 / 20 074 текста в train / validation / test.

Для тональности сначала обучен линейный baseline, затем полностью дообучен [cointegrated/rubert-tiny2](https://huggingface.co/cointegrated/rubert-tiny2) с новым классификатором трёх классов. Использовались AdamW, кросс-энтропия, батч 16, длина 256, три эпохи и выбор лучшей эпохи по validation Macro-F1. Конфигурация и контрольные суммы весов находятся в [artifacts/model_manifest.json](artifacts/model_manifest.json).

Метки: `0` — нейтральная, `1` — положительная, `2` — отрицательная.

## Ограничения

В данных встречаются сомнительные метки. Тест предварительно очищен с учётом конфликтов в обоих исходных файлах, поэтому метрики относятся к подготовленной выборке. Проверка близких дубликатов, группировка по источникам и доверительные интервалы не выполнялись. Часть длинных текстов обрезается. В NMF есть общие речевые шаблоны и пересекающиеся компоненты.

Факультативная оптимизация CPU не выполнялась. Способы улучшения описаны в notebook без реализации. Добавленные скрипты нужны для передачи и демонстрации уже обученной модели; новых обучающих экспериментов в них нет.

## Файлы


Веса BERT не входят в историю Git: `model.safetensors` превышает ограничение обычных GitHub-коммитов в 100 МиБ. Архив распространяется через Releases. `.venv`, исходные CSV, промежуточные файлы и последняя контрольная точка исключены через `.gitignore`.

Проверка результатов без обучения и установки ML-библиотек

```bash
python3 scripts/validate_submission.py
```

Для повторной упаковки уже имеющихся весов

```bash
python3 scripts/create_model_release.py
```

Архив и SHA-256 будут записаны в `.release-assets/`. Исходная модель RuBERT-tiny2 опубликована автором под MIT; условия исходных датасетов нужно смотреть у их авторов.
